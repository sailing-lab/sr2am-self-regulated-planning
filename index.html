Abstract

Large language models (LLMs) are increasingly deployed as interactive agents that reason, use tools, and act over long horizons. However, current agentic LLMs typically rely on black-box chain-of-thought, where planning behavior is expected to emerge implicitly from unconstrained optimization with reinforcement learning (RL). Without control over planning presence, depth, or structure, these systems often rely on scaling reasoning length as the primary mechanism for improvement during training, leading to inefficient token consumption that does not reliably translate to accuracy gains. Prior approaches seek to contain reasoning growth by building capabilities such as effort adaptation, coarse mode-routing, and multi-agent distillation, which fall short of either explicit planning, per-turn regulation, or combination with free-formed reasoning.

We introduce SRAM, an agentic LLM that combines the strengths of existing approaches while enabling more advanced planning features. Specifically, SRAM augments conventional thinking-acting LLMs with an explicit configurator and structured planner as part of its reasoning process. At each turn, the configurator decides whether to plan, continue an existing plan, or act directly; when invoked, the planner constructs explicit plans grounded in predicted future states and controlled planning depth.

These components operate alongside free-form reasoning, separating self-regulation, planning, and execution while preserving end-to-end expressiveness. We realize this framework through supervised data encoding self-regulated planning structure followed by RL for task success, yielding SRAM-v0.1-8B and SRAM-v1.0-30B.

Across mathematical reasoning, scientific problem-solving, tabular data analysis, and web information seeking, SRAM-v0.1-8B and SRAM-v1.0-30B achieve overall Pass@1 competitive with systems at 120–355B and 685B–1T parameters, respectively, while consuming up to 25–95% fewer reasoning tokens than comparably sized agentic LLMs. Analysis shows that RL increases average plan depth by 22.8% while planning frequency grows only 2.0%, suggesting the model learns to plan at longer horizons without overly frequent planning.

The SRAM agent at each turn: the configurator decides whether to plan, continue an existing plan, or act directly. When planning is invoked, the planner builds a structured sequence of proposed actions and predicted future states. All three components run within a single LLM.

How SRAM Works

At each step, SRAM regulates its own reasoning, deciding whether to plan, how deep to plan, and when to act.

  • Configurator — meta-cognitive gating: decides at every step whether to plan, continue a prior plan, or act immediately (inspired by how humans regulate deliberation based on urgency and complexity)
  • Planner — when invoked, builds a structured sequence of proposed actions and predicted future states, grounding execution in anticipated consequences rather than just the next action
  • Actor — executes actions (web search, browser, Python sandbox) conditioned on the plan and current context

Stage 1: Supervised Self-Regulation Data Construction

Instead of writing planning data from scratch, we reconstruct self-regulated structure from existing reasoning LLM traces. An annotator LLM reads each step and injects a configurator decision and, when needed, an explicit structured plan.

Reconstruct self-regulation

Annotator LLM reads each step and outputs: (1) plan? yes/no, (2) if yes, a structured plan of proposed actions + predicted future states. Free-form reasoning is preserved.

Fine-tune

SFT on structured data

Fine-tune an open-weight LLM on the annotated trajectories. Model learns when to plan, how deep to plan, and how to integrate plans with free-form reasoning.

Why this works: Planning depth is explicitly controllable (web tasks get shallower plans (≤2 steps) due to environmental unpredictability, and science tasks allow deeper planning horizons).

Stage 2: Reinforcement Learning Refinement

RL teaches the model to coordinate self-regulation and planning for task success. This optimizes not just for thinking more, but for planning at the right depth and frequency.

Reward Signal

1.0 Correct answer + proper structure
0.8 Correct answer, structure issues
0.2 Wrong answer, structure correct
0.0 Wrong answer, no structure

Structure reward ensures gradient signal even on failed trajectories.

What RL learns

  • Plan at longer horizons when it matters
    avg. plan depth +22.8% (1.67 → 2.05 steps)
  • Don't over-plan — frequency barely changes
    planning frequency +2.0% (84.4% → 86.4%)
  • Stay within context budgets — no runaway token growth
    black-box RL hits 22.4% context overflow; self-regulated model stays within practical limits

Performance

Small models, large-model accuracy

The trend line shows what accuracy you'd expect for a given parameter count. Both SRAM models land above it: SRAM-8B competes with systems at 120–355B, SRAM-30B with systems at 685B–1T. Marker color encodes token usage: greener = fewer tokens.

Efficiency

Up to 20× fewer reasoning tokens across every task type

SRAM achieves competitive accuracy while using dramatically fewer reasoning tokens. The efficiency advantage holds across Math, Science, Tabular, and Web tasks. Bars show token usage (log scale); dots show Pass@1.

Avg. reasoning tokens per query (bars, log scale) vs. Pass@1 (dots) for four 30/32B agentic LLMs, broken down by task category. SRAM-v1.0-30B achieves competitive scores using up to 20× fewer tokens than ASearcher-Web-QWQ-v2.

Training Analysis

RL makes plans deeper, not more frequent

After RL training, the proportion of unplanned turns barely changes, but multi-step plans become far more common. The model learns to plan at longer horizons when it matters, rather than planning more often or thinking longer without direction.

Plan depth distribution before (light) and after (dark) 200 RL steps. Left: 3+ step plans nearly triple (5.3% → 14.9%); unplanned turns stay stable (15.6% → 13.6%). Right: avg. plan depth by task — science gains most (+32.7%), web gains least (+20.9%).
