Case Studies

Comparing SRAM's self-regulated planning against baselines on real tasks.

GAIA

How many nonindigenous crocodiles were found in Florida from the year 2000 through 2020?

SRAM-v1.0-30B Ours
45 messages

Navigates USGS NAS database, identifies 6 Nile + 1 Morelet's records. Plans a verification step and cross-validates against an authoritative source, correcting to 6.

Anticipatory planning with explicit verification step
SFT Checkpoint
69 messages

Same raw data found (6 Nile + 1 Morelet's = 7), but plans only say "provide final answer." Accepts the direct tally without cross-validation.

Reactive, single-step planning — no verification
Distillation Baseline
67 messages

Same tally of 7. Spends many turns trying the NAS REST API with zero results. No structured planning to seek external validation.

No planning structure to guide fallback strategy
AIME 2024

Find the number of rectangles that can be formed inside a fixed regular dodecagon where each side lies on a side or diagonal.

SRAM-v1.0-30B Ours
11 messages

Plan anticipates fallbacks ("if not found, enumerate computationally"). Rejects flawed answer of 66 from Gauthmath, pivots efficiently to a valid source confirming 315.

5.5× fewer messages than SFT, with fallback strategy
SFT Checkpoint
61 messages

Reaches same answer (315) but takes 61 messages. Plans specify only the immediate next step, spending 25+ turns on blocked AoPS workarounds.

Correct but highly inefficient — no fallback planning
Distillation Baseline
57 messages

Makes a fundamental error early (assumes vertex-only rectangles → 15). Without explicit state tracking, this assumption is never flagged for re-examination.

No state tracking to catch conceptual errors

73 messages

Finds "Sent-du-Bec" in first search but plans repeatedly flag "cross-validate with etymology databases." 60+ messages of fruitless verification before committing with a formatting error.

Anticipatory planning over-triggers on simple tasks
SFT Checkpoint

Finds same crossword snippet. Accepts "Sent-du-Bec" after 1–2 confirmatory searches. 3/3 correct.

Appropriately calibrated — stops early
Distillation Baseline
11 messages

Accepts "Sent-du-Bec" after one confirmatory search. 3/3 correct.

Quick acceptance — correct for this task
